# Haven Tashkent — team files

Posters, flyers, logos, post copy and school-talk slides for the **Haven Tashkent** organizing team.
Haven Tashkent is a free two-day game jam for teenagers (13–18) on **14–15 November 2026**, part of [Hack Club Haven](https://haven.hackclub.com).

> **You don't need GitHub.** Open **[haventash.xyz → Files](https://haventash.xyz/#/files)** and sign in. Every file here is there too, with previews and download buttons, plus our Canva links. Each task in the Hub shows the files it needs.

## Post style

- Open with **▶️ PRESS START**.
- Sign off with **"Two days. One game. Made by you."**
- No heart emojis.
- Uzbek first, then Russian, then English. A native speaker checks every public post.
- Never announce anything unconfirmed (venue, prizes, sponsors).
- Never compare us with NASA Space Apps.

## Rules for this repo (it's public)

- **No phone numbers, emails, Telegram handles or home addresses**, ours or anyone else's.
- **No photos of participants** unless they and a parent agreed in writing.
- **No Canva *edit* links.** Anyone could change the design. Canva links live in the Hub (sign-in only).
- Contact lists and trackers live in Google Sheets, linked from the Hub. They never go here.
- Brand assets in `brand-kit/` come from Hack Club HQ's public [Haven brand guide](https://www.figma.com/design/V1S8l3ju7K75ABGowht1gj/-PUBLIC--Haven-Brand-Guide).
